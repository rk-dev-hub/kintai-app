# 勤怠管理アプリ — 概要と決定事項

接続情報は環境変数で管理し、リポジトリにはダミー値のみを含む。ホスティング先ごとのデプロイ構成は含めず、導入先の環境に合わせて設定する（手順は README「本番環境の設定」）。

## 確定した要件（ヒアリング結果）

| 項目             | 決定                                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------------------- |
| 機能スコープ     | 打刻（出退勤・休憩）＋ 休暇・打刻修正の申請 ＋ 承認フロー                                                       |
| 利用者ロール     | 従業員（EMPLOYEE）＋ 管理者（ADMIN）の2ロール／単一組織                                                         |
| 技術スタック     | Next.js (App Router) フルスタック ＋ TypeScript ＋ Prisma                                                       |
| 開発用 DB        | PostgreSQL（Docker Compose 同梱）。Prisma 経由で差し替え可                                                      |
| 認証             | 管理者がユーザーを発行。セルフサインアップなし。パスワードは bcrypt                                             |
| 残業・割増ルール | 労基法準拠の固定ロジック（週40h／日8h、深夜25%、法定休日35%、月60h超50%）。所定時間・締め日など主要値のみ設定可 |
| 勤務体系         | 固定時間制のみ（所定始業・終業・休憩）                                                                          |
| 休暇粒度         | 全日 ＋ 半日（午前／午後）                                                                                      |
| 打刻の丸め       | 1分単位で記録・丸めなし。誤打刻/打刻漏れは修正申請 → 管理者承認。監査ログを保持                                 |
| 祝日・法定休日   | 日本の祝日データを内蔵（更新スクリプト同梱）。法定休日は日曜固定＋マスタで変更可。所定休日も設定                |
| 出力             | 画面表示 ＋ 汎用 CSV ＋ 印刷用 PDF（月次勤務表・集計）                                                          |
| 進め方           | 要件＋設計書を先に作りレビュー → 承認後に実装                                                                   |
